## 👋 About me

I'm a **data analyst** with a foot in two worlds: **healthcare analytics** and **blockchain**. I build the systems behind the numbers: pipelines that pull data from many sources, clean it, check it and turn it into dashboards that update by themselves. On the blockchain side, I write and audit smart contracts, looking for the bugs before attackers do.

- 🏥 **Healthcare analytics:** clinic visits, laboratory and pharmacy sales, memberships, patient flow, senior care
- 🔧 **Data engineering:** ETL in Python and SQL, layered warehouses, REST API integration, scheduling
- 📊 **Business intelligence:** Power BI (DAX, Power Query, data modelling) and Excel dashboards built for decision makers
- ✅ **Numbers you can trust:** automatic reconciliation checks, so nothing is published unless it adds up
- 🔒 **Privacy first:** patient details kept out of reports, read-only reporting logins, no secrets in code
- ⛓️ **Blockchain:** Solidity with Foundry, Python smart contracts with Vyper, smart contract security audits

## 🚀 Featured project

### [Clinic Analytics Pipeline](https://github.com/Tiannah123/clinic-analytics-pipeline)
An automated data pipeline and reporting system for a multi-clinic healthcare provider (public version on synthetic data).

<table>
  <tr>
    <td align="center"><h3>6</h3>data sources joined<br/>every night</td>
    <td align="center"><h3>228</h3>automatic checks<br/>on every report</td>
    <td align="center"><h3>11</h3>Power BI pages,<br/>built as code</td>
    <td align="center"><h3>143 → 22</h3>messy spellings<br/>cleaned to clean areas</td>
  </tr>
</table>

- **Warehouse:** raw → staging → mart in PostgreSQL, with versioned migrations and a full run log
- **Pipeline:** a nightly Python ETL that stops itself before publishing bad data
- **API sync:** EMR REST API integration within the vendor's limits (rate limiting, retries, incremental sync)
- **Excel dashboard:** rebuilt every night; every table is checked against the database
- **Power BI report:** generated from code (TMDL and PBIR), with synced date filters, 56 DAX measures, year-on-year on matching dates and a membership renewal call list
